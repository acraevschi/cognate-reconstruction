# Local data

The supported harness does not require a bulk download. It reads an existing
local Lexibank/CLDF dataset through `prepare-lexibank`.

Large `stage1_*.jsonl` and `stage2_*.jsonl` files already present in this
directory are preserved legacy corpus artifacts. They are intentionally not
moved or regenerated by the migration because they may be multi-gigabyte,
untracked local research outputs. They are not trajectory data and are not the
supported future fine-tuning contract.

The former split metadata remains in the archived
[predecessor repository](https://github.com/acraevschi/llm_cognate_reflexes).
The supported copy of
`historical_lineages.csv` contains curated, dataset-scoped ancestry
provenance. It does not define runtime traversal: `prepare-lexibank` can use
it only to bind attested forms to an explicitly labelled internal node in a
separately supplied Newick tree, as either hidden targets or visible anchors.

Local Lexibank and Glottolog checkouts remain user-managed inputs and are not
modified by the harness.
