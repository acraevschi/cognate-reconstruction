# Local data

Nothing in this directory is downloaded or generated by the harness, and a
fresh clone needs none of it to run the checked-in fixture smoke tests. Only
`historical_lineages.csv` is tracked in git.

## Tracked

- `historical_lineages.csv` — curated, dataset-scoped ancestry provenance. It
  does not define runtime traversal: `prepare-lexibank` can use it only to bind
  attested forms to an explicitly labelled internal node in a separately
  supplied Newick tree, as either hidden targets or visible anchors. Used by
  `make smoke-iecor-historical` and `tests/workbench/test_historical_bindings.py`.

## User-managed local checkouts (git-ignored, not present on a fresh clone)

- `lexibank/<dataset>/` — CLDF datasets read directly by
  `prepare-lexibank --dataset data/lexibank/<dataset>`. Clone only the datasets
  you actually want to run; `make smoke-iecor-historical` expects `lexibank/iecor`.
  The checked-in `examples/lexibank_fixture` covers the fresh-clone path.
- `glottolog/` — optional. No code path reads it, and it is not needed to run
  anything. Glottocode handling is a hardcoded compatibility table
  (`ingestion/compatibility.py`) plus passthrough of the CLDF `Glottocode`
  column; supplied Newick trees use dataset-scoped leaf IDs, not Glottocodes.
  It is only a manual reference for deriving a classification tree or adding a
  compatibility rule. A full checkout is ~1.9 GB, mostly git history; if you
  want it offline, take the data only:

  ```bash
  git clone --depth 1 https://github.com/glottolog/glottolog.git data/glottolog
  ```

## Not part of this repository

Stage-1/Stage-2 JSONL corpora belong to the superseded fine-tuning scope. The
harness reads CLDF and Newick directly and never consumes that format, so those
files are not produced, read, or documented here. The generator, split manifest,
and dataset-exception notes remain in the archived
[predecessor repository](https://github.com/acraevschi/llm_cognate_reflexes).
